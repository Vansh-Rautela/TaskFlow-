# Security Questionnaire & SOC 2 Requests

Enterprise customers frequently perform vendor due diligence before signing or renewing an agreement. AcmeFlow supports this through security reviews, security questionnaires, and documentation requests such as SOC 2 reports. These processes are available to Enterprise customers and are coordinated as part of the enterprise relationship.

This document explains how security questionnaires and SOC 2 documentation requests are handled and what a support agent should do when one arrives.

## Security Reviews for Enterprise Customers

Enterprise agreements may include security reviews as part of the procurement process. Security reviews typically cover:

- Data handling and storage practices.
- Access control, including SSO/SAML and SCIM where contracted.
- Audit controls and logging capabilities.
- Subprocessors and data processing arrangements.
- Incident response and breach notification provisions.

The scope of a security review is defined by the customer's requirements and the terms of the agreement.

## Security Questionnaires

Customers may submit a security questionnaire during onboarding, renewal, or contract negotiations. Questionnaires are reviewed and completed by the appropriate AcmeFlow team. Response time and format depend on the customer's request and the agreement.

Questionnaires are coordinated through the account team. Where a dedicated account manager is assigned, that person is the primary contact for the questionnaire. Otherwise, the request is routed to Enterprise Operations for coordination.

**Example (labeled):** In this example, Northwind Logistics submits a security questionnaire as part of its renewal of MSAA-2026-0833. The dedicated account manager coordinates the response with the security and compliance team, and a completed questionnaire is returned within the timeframe agreed in the renewal discussions.

## SOC 2 Documentation Requests

Customers may request SOC 2 documentation as part of their due diligence. These requests are handled under the terms of the signed agreement, including any confidentiality obligations.

SOC 2 documentation is shared through a controlled process. Supporting documentation and reports are not posted publicly or distributed outside the approved channel. Customers under a non-disclosure agreement receive the documentation through the account team.

**Example (labeled):** As part of its evaluation of a new Enterprise contract, Meridian Health Partners requests the SOC 2 report under the confidentiality terms of the evaluation agreement. The report is provided through the account team's secure channel, and no report content is shared outside the approved workflow.

## Confidentiality and Scope

All security documentation, including completed questionnaires and SOC 2 reports, is shared under the confidentiality and non-disclosure obligations that apply between AcmeFlow and the customer. The customer's signed Enterprise agreement takes precedence over the standard self-service policy where the two differ, including for security and compliance processes.

## How Support Agents Should Handle These Requests

When a support agent receives a security questionnaire or a request for SOC 2 documentation:

- Confirm the account is governed by an Enterprise agreement and check whether the request is covered by it.
- Coordinate through the assigned dedicated account manager or Enterprise Operations.
- Do not attach or forward SOC 2 reports or completed questionnaires from standard support channels.
- Retrieve the applicable confidentiality and delivery terms from the agreement before responding.

Account-specific security documentation is never fabricated as an answer; the agent verifies the request and routes it to the correct team.
